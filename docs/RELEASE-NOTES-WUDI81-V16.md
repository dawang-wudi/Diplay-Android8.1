## DiPlay 车机版 · 使用 iPhone 的麦克风

在同一分支上增加「使用 iPhone 的麦克风」，让车机没有麦克风时通话和 Siri 改用 iPhone 自己的麦克风。

**v45 可直接覆盖升级到 v46，包名不变，设置全部保留。**

### 本版改动

**新增：使用 iPhone 的麦克风（实验性）**

- 车机没有麦克风时，让通话和 Siri 改用 iPhone 自己的麦克风。
- 实现方式是在 AirPlay `/info` 响应里**省略 `audioInputFormats`**，即告知 iPhone
  本接收端不提供音频输入；同时不再启动本地麦克风采集，省掉无意义的录音。
- 新增设置项「使用 iPhone 的麦克风」：
  - **DiPlay 主设置页 → 音频路由**
  - **CarPlay 主机设置页 → 音频**
- **默认关闭。** 有麦克风的车机应继续使用车机麦克风（离驾驶员更近、通话质量更好），
  只有完全没有麦克风的车机才需要打开。
- **改动生效需要重新连接 CarPlay**，因为 `/info` 只在会话建立时发送一次。

**文档更新**

- README 与版本说明中「自动开启车机热点的端到端效果」由「待实车确认」更新为
  **已实车确认**：冷启动（热点原本关着）**5.7 秒**拉起热点，之后每次 **1.1~1.6 秒**。

### ⚠️ 关于麦克风开关的重要说明

`audioInputFormats` 只是**协议层面的能力声明**。**iOS 是否真的会回退到 iPhone 麦克风，
尚未实车验证。**

- **如果有效**：通话和 Siri 会使用 iPhone 的麦克风。
- **如果无效**：说明 iOS 在 CarPlay 下强制要求车机提供麦克风输入，这条路走不通，
  需要外接麦克风到车机。

**验证方法**：打开开关 → 重新连接 CarPlay → **打一通电话，问对方能不能听到你**。
这是最直接的判断方式。

**这个开关默认关闭，所以本版在默认配置下的行为与 v45 完全一致**，
不打开开关就不会有任何风险。

### 使用自动开启热点仍需授权

「修改系统设置」是特殊访问权限，**不会**出现在「应用信息 → 权限」列表里：

> 设置 → 应用 → 特殊访问（特殊应用权限）→ **修改系统设置** → 找到 DiPlay → 打开

也可用命令行：

```sh
adb shell appops set com.shihab.diplay.wudi81v15 WRITE_SETTINGS allow
```
